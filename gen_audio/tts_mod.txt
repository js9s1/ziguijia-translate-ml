# Chatterbox TTS modifications
# Recorded: 2026-05-15
# All changes are in /home/js9s/src/chatterbox/src/chatterbox/

## 1. s3tokenizer/__init__.py — Fix out-of-range special token crash

**Problem:** T3 can generate speech tokens up to 8193 (speech_tokens_dict_size=8194), but the flow model's input_embedding only has vocab_size=6561. The old drop_invalid_tokens only stripped SOS(6561) and EOS(6562), allowing tokens 6563–8193 to reach the embedding layer and cause `IndexError: index out of range in self`.

**Fix:** Changed drop_invalid_tokens to filter all tokens >= SPEECH_VOCAB_SIZE (6561) using `x[x < SPEECH_VOCAB_SIZE]`, matching the already-correct version in s3gen/s3gen.py. Removed orphaned SOS/EOS constants.

## 2. mtl_tts.py — Add map_location="cpu" to torch.load calls

**Problem:** Loading model weights with torch.load(..., weights_only=True) without map_location raises a RuntimeError on CPU-only machines.

**Fix:** Added `map_location="cpu"` to both ve.pt and s3gen.pt torch.load calls.

## 3. t3/t3.py — Force eager attention to avoid SDPA warnings

**Problem:** PyTorch SDPA (scaled dot-product attention) warnings during transformer inference.

**Fix:** Added code to force eager attention mode by disabling flash SDPA and mem-efficient SDPA backends at PyTorch level.

## 4. t3/inference/alignment_stream_analyzer.py — Tighter hallucination/repetition detection

**Problem:** Hallucination patterns (repeating tokens, long-tail activations) were not caught aggressively enough.

**Fix:** 
- Reduced long_tail activation threshold from 5 (200ms) to 3 (120ms)
- Expanded token repetition detection: catches 4x identical tokens, alternating patterns (A,B,A,B or A,A,B,B), and 3x same in last 4

## V3 upgrade (2026-11-08)

Chatterbox Multilingual V3 is not in PyPI 0.1.7. The daemon now installs
upstream git commit `ab55923c27757c90cfcc407baa57dc25a7d25217` and selects
the checkpoint via `CHATTERBOX_T3_MODEL` (default `v3`).

Status of the patches above with V3:

- **#1 `drop_invalid_tokens` vocabulary guard — still needed.**
  V3 still has T3 `speech_tokens_dict_size=8194` versus the flow model's
  6561-token embedding, and upstream still only strips SOS/EOS. Apply
  `patches/chatterbox_v3_drop_invalid_tokens.patch` after every reinstall:
  `patch -p1 -d "$(~/.pyenv/versions/3.11.14/bin/python3.11 -c 'import chatterbox,pathlib;print(pathlib.Path(chatterbox.__file__).parent.parent)')" < gen_audio/patches/chatterbox_v3_drop_invalid_tokens.patch`.
- **#2 `mtl_tts.py` `map_location="cpu"` — already upstream.** No separate patch.
- **#3 eager attention / SDPA disable — optional.** Upstream V3 sets
  `output_attentions=False`; only reapply if ROCm warnings or NaNs persist.
- **#4 `alignment_stream_analyzer` — obsolete.** Upstream V3 removes the file
  and all references to it. Do not port this patch.

V3 also lowers `repetition_penalty` from 2.0 to 1.2 and drops the final speech
token, so the old hallucination analyzer is intentionally gone.
