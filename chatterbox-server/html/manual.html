📖 使用手册

宁师的视频翻译工具 · 视频翻译与语音克隆

一、工具简介

本工具使用 AI 技术，将宁师的视频翻译成其他语言，并用克隆的宁师声音重新配音： 翻译好的音频会按照原视频的时间节奏进行拉伸对齐，视频画面也会相应调整，最终生成带有双语字幕的完整视频。

支持的翻译语言：英语、日语、韩语、印尼语、泰语、越南语、中文、德语、法语、西班牙语、葡萄牙语、俄语、阿拉伯语、希伯来语、印地语、马来语、荷兰语、挪威语、波兰语、瑞典语、斯瓦希里语、土耳其语、丹麦语、希腊语、芬兰语、意大利语等。

二、登录与账户

  • 首次使用请先注册账户，注册后登录即可使用全部功能。
  • 登录后右上角可以看到自己的头像和昵称，并可以进入「我的任务」页面查看自己提交的所有任务。
  • 忘记密码可以通过注册邮箱重置密码。

三、功能说明

1. 翻译自定义视频（推荐）

上传你自己的视频文件（如宁师开示的下载视频），系统生成翻译音轨并合成新视频。

翻译模式有四种：

模式说明
上传SRT字幕自己准备英文字幕文件（.srt），系统按字幕生成配音并调整视频。字幕内容越准确，效果越好。
语音识别翻译（Whisper + HY-MT）系统自动识别视频中的中文语音，生成中文字幕并翻译成目标语言，无需上传字幕。
OCR识别翻译（RapidVideOCR + HY-MT）系统通过画面文字识别（OCR）提取视频中烧录的中文字幕，翻译后再配音。适合视频中没有清晰人声、但画面有字幕的情况。
OCR识别并生成翻译字幕只做OCR和翻译，生成翻译好的字幕文件，不生成音频和视频。
选择「上传SRT字幕」模式时，字幕时间必须与上传的视频片段对应，否则系统会拒绝处理。SRT 文件必须是单一语言（中英对照的双语字幕会被拒绝）；中文里偶尔出现英文单词（网址、缩写等）不影响。请不要上传带BOM的SRT文件。

2. 翻译官方宁视频

输入子归家网站上的视频号（例如 25339），系统自动下载视频。翻译模式与「自定义视频」相同：可以上传SRT，也可以让系统自动识别翻译。

3. 从SRT生成音轨

只上传字幕文件（.srt），系统批量生成整条翻译语音轨道（不处理视频）。适合只需要音频、或自己用其他软件合成视频的情况。字幕同样要求单一语言（双语字幕会被拒绝）。

4. 生成翻译语音（克隆宁师语音）

输入一段文字（或上传文本文件），直接生成一段用宁师声音朗读的语音。适合试听语音效果、制作单段语音。

单次输入文字最多 500 字。

5. 从视频提取字幕（OCR）

上传视频，仅提取画面中的中文字幕生成SRT文件，不做翻译和配音。

四、参数说明

参数说明建议
目标语言翻译成的语言。按需选择，一般保持默认（英语）。
温度（temperature）语音生成的随机性。越高语音变化越大，越低越稳定。一般保持默认 0.5。
CFG权重语音对文本的忠实度控制。一般保持默认。
夸张度（exaggeration）声音表现力/情绪幅度。一般保持默认。
模糊处理生成视频时对画面下方的原中文字幕区域做模糊处理。视频自带中文字幕时建议开启「是」。

五、任务状态与结果

  • 提交后任务进入队列排队。任务按顺序执行，同一时间只处理一个任务；长任务可能因为 GPU 过热保护而短暂暂停，属正常现象。
  • 可以在「我的任务」页面或提交后跳转的页面查看任务状态：排队中 → 处理中 → 完成 / 失败。处理中会显示当前步骤（如「正在生成音频…」）。
  • 任务完成后进入「处理结果」页面，可以查看和下载生成的文件。

生成的文件说明

文件名说明
output_final.mp4最终视频：翻译配音 + 英文字幕，可直接下载观看。
output_modified.mp4中间文件：视频画面已按新音频调整节奏（无字幕）。
output.wav翻译语音轨道（克隆声音）。
output_adjusted.srt调整时间后的英文字幕（与最终视频同步）。
orig_zh_adjusted.wav调整时间后的原中文音轨，可用于自行剪辑对照。
changed_segments.json各字幕段落的时间调整记录（供工具内部使用）。

六、字幕编辑与重新合成

  • 在结果页可以直接在线编辑字幕文件（除 output_adjusted.srt 外的 .srt 文件），保存后再提交任务，系统会从编辑后的字幕重新生成音轨和视频。
  • 任务失败或效果不满意时，可以点击重新提交；已完成的段落会自动复用缓存，只重新生成有变化的部分，速度很快。

七、字幕书写技巧

  • 每条字幕建议控制在 120 个字符以内，过长会自动分段。
  • 在字幕文字中加入 <秒数>（例如 ……就是这样。<1.5>接下来……）可以在配音中插入指定时长的停顿。
  • 纯符号、无文字的字幕（如「♪♪」）会生成静音；只要含文字，即使很短（如「好。」「So,」）也会正常配音。
  • 短句、短词会被正常朗读，不会因为字数少而变成静音。
  • 整份 SRT 文件请使用单一语言（例如整份全英文，或整份全中文）。如果中英两种文字都占较大比例（中英对照的双语字幕），系统会拒绝上传；中文里偶尔出现的英文网址、缩写不影响。

八、常见问题

问题解答
上传视频有什么要求？支持常见格式（mp4 / mov 等），建议单文件不要过大；上传SRT模式要求字幕与视频片段时长基本一致（±5%以内）。
SRT 上传失败或乱码？请使用 UTF-8 编码的 .srt 文件（系统兼容 GBK/Big5，但建议 UTF-8）；不要上传以「output」开头的文件。
SRT 被提示「包含多种语言」？系统要求 SRT 为单一语言，中英对照的双语字幕会被拒绝。请只保留目标语言的文字（如只保留英文翻译行），删除另一种语言后重新上传；中文里偶尔的英文单词（网址、缩写）不影响。
任务要处理多久？音频生成约 5–15 分钟，视频合成约 1–3 分钟；排队时间取决于队列中前面的任务数量。
为什么个别段落是静音？个别段落可能因语音模型偶发故障而静音。重新提交任务即可自动重试这些段落。
视频和字幕不同步？重新提交任务；系统会重新对齐音画。如仍不同步，请检查上传的SRT是否与视频片段匹配。
可以下载中间文件吗？可以。结果页文件列表中所有文件均可单独下载。
