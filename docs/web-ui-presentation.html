参数说明
生成参数详解
温度 · 目标语言 · CFG 权重 · 夸张度
🌡️ 温度 (Temperature)
范围： 0.5 – 1.5  |  默认： 0.8

控制生成语音的随机性和多样性。
较低值（0.5–0.7）→ 稳定、一致性高，适合正式内容
较高值（0.8–1.5）→ 更富变化，适合创意内容

提示： 温度越高，同一段文字每次生成的语音越不同。
🌐 目标语言 (Target Language)
支持： 23 种语言（🇬🇧 英语、🇨🇳 中文、🇯🇵 日语、🇰🇷 韩语、🇫🇷 法语、🇩🇪 德语、🇪🇸 西班牙语 等）

决定 TTS 模型生成的语音语言。
自动翻译模式还控制 HY-MT 机器翻译的输出语言。

提示： 选择与输入文本匹配的语言可获最佳效果。
⚖️ CFG 权重 (Classifier-Free Guidance)
范围： 0.0 – 1.5  |  默认： 0.5

控制模型对输入条件的遵循程度。
较低值（0.0–0.3）→ 更多自由发挥，语音更自然
较高值（0.6–1.5）→ 更严格遵循提示，发音更清晰

提示： 对复杂文本可适当提高 CFG 权重以改善发音准确性。
🎭 夸张度 (Exaggeration)
范围： 0.0 – 1.0  |  默认： 0.5

控制语音的情感表现力和语调起伏。
较低值（0.0–0.3）→ 平淡、中性，适合新闻或说明
较高值（0.6–1.0）→ 富有情感和韵律，适合故事或演讲

提示： 夸张度会影响 speaker embedding 的情感维度。

从 SRT 生成音轨
批量字幕转语音
SRT 功能
字幕转语音操作指南
上传 SRT → 批量 TTS → 分段语音文件

SRT 处理流程

  • 上传 .srt 标准字幕文件
  • 调节 温度 + 目标语言 + CFG 权重 + 夸张度
  • 系统自动解析每条字幕的时间轴
  • 逐条调用 TTS 引擎生成对应语音
  • 输出按时间轴排序的 WAV 文件列表
输出： 每个 SRT 段落对应一个 WAV 文件，可在结果页播放/下载

SRT 文件格式示例

1
00:00:01,000 --> 00:00:04,000
John: Hello, welcome to this video.

2
00:00:05,000 --> 00:00:09,000
Mary: Today we will learn about AI translation.

3
00:00:10,000 --> 00:00:14,500
John: Let's get started!

视频翻译
🎬 翻译官方宁视频
为官方视频配上翻译音频

操作步骤

1
输入 视频号 定位官方宁视频
2
上传对应翻译 SRT 字幕文件
3
选择 模糊处理（是/否）
4
调节温度参数，提交任务

后端处理流程

# srt_action.py → _run_video_job()

1. 解析 video_number 定位官方视频源文件
2. 调用 gen_video_orig.sh 脚本：
   ├─ gen_audio.py 解析 SRT 字幕
   ├─ Chatterbox Multilingual TTS 逐条生成翻译语音
   ├─ 根据时间轴拼接完整音频轨道
   ├─ FFmpeg 合并音频与原视频
   └─ 可选模糊处理（中文字幕）
3. 输出 output_final.mp4

# 输出目录: /video/{video_number}-{access_code}/
输出： 含翻译配音的 MP4 视频文件

视频翻译
🌐 翻译自定义视频
上传任意视频进行翻译配音

📋 SRT 模式

1
上传 视频文件 + SRT 字幕
2
调节温度参数，提交任务
后端： Chatterbox Multilingual TTS 为字幕生成多语言音频 → gen_video.py 合并到视频

🤖 自动模式

1
仅上传 视频文件（无需字幕）
2
调节温度参数，提交任务

后端处理流程

# srt_action.py 中的两种任务处理函数

【SRT 模式】_run_video_custom_job()
  Step 1: gen_audio.py 解析上传的 SRT
         ├─ Chatterbox Multilingual TTS 逐条生成翻译语音
         └─ 输出 adjusted SRT + WAV
  Step 2: gen_video.py
         ├─ 将翻译音轨合成到视频中
         └─ 输出 output_modified.mp4

【自动模式】_run_video_auto_job()
  Step 0: FFmpeg 提取音频
  Step 1: Whisper.cpp ASR → 中文 SRT
  Step 2: HY-MT 机器翻译 → 目标语言 SRT
  Step 3: gen_audio.py 生成配音
  Step 4: gen_video.py 合成最终视频
自动模式： 无需字幕文件，系统自动完成语音识别 + 翻译（支持 23 种目标语言）+ 配音全流程
